## 一、技术架构总览

```
┌─────────────────────────────────────────────────────────────┐
│                    展现层 (Presentation)                      │
│  PC Web: Vue 3 + Vite + Element Plus + TS        PDA: Uni-app│
│  WebSocket: SignalR Hub (30s 自动刷新)                       │
├─────────────────────────────────────────────────────────────┤
│                    业务层 (Application)                       │
│  .NET 9 + ASP.NET Core · RESTful API · SignalR               │
│  路由: /api/v1/{module}/{resource}                           │
├─────────────────────────────────────────────────────────────┤
│                    AI 层 (Intelligence)                       │
│  Python FastAPI · gRPC (实时风险评分) + REST (离线分析)       │
│  RabbitMQ/Kafka (异步训练、批量处理)                          │
├─────────────────────────────────────────────────────────────┤
│                    数据层 (Data)                              │
│  MySQL 8.0+ (主库) · Redis (缓存) · MinIO (文件)             │
│  InfluxDB (时序) · Milvus (向量检索)                         │
└─────────────────────────────────────────────────────────────┘
```

### 桥接模式

| 交互方式 | 协议 | 适用场景 |
|---------|------|---------|
| **gRPC** | HTTP/2 + Protobuf | 高频推理（实时 AI 风险评分） |
| **REST API** | JSON/HTTP | 离线分析（根因分析、报表统计） |
| **事件总线** | RabbitMQ/Kafka | 异步任务（大模型训练、批量历史数据清洗） |

## 二、开发阶段与里程碑

> **总计划**: 11 个 Sprint，每 Sprint 2 周，总计约 22 周（约 5.5 个月）
> **并行策略**: 前端（Vue3）和后端（.NET9）在每个 Sprint 并行开发，AI 服务从 Sprint 4 开始并行

### 里程碑总览

| 里程碑 | Sprint | 完成时间 | 交付物 |
|--------|--------|---------|--------|
| **M0 — 项目启动** | S0 | W1-2 | 环境搭建、代码仓库、CI/CD 流水线 |
| **M1 — 基础框架** | S1-2 | W3-6 | 全局 Tab 架构、Auth、基础数据 M02、参数配置 M02.5 |
| **M2 — 核心检验** | S3-5 | W7-14 | IQC M03、IPQC M04、FQC/OQC M05 |

## 六、风险与缓解
